Projeler

Anka: Afet Sonrası Yaşam Sinyali Tespit Sistemi

Deprem sonrası enkaz altında kalan afetzedelerin konumunu, ek donanım olmadan yalnızca akıllı telefonlarla tespit etmeyi amaçlayan Android tabanlı sistem.

D2D Communication Mesh Networking Indoor Positioning Kotlin

Derman: Afet Sonrası Yardım Eşleştirme Platformu

Afet bölgesindeki ihtiyaç sahiplerini yardım edebilecek kişilerle konum bazlı eşleştiren, yapay zeka destekli web platformu. Afetzede ve Yardımcı için ayrı paneller sunar; talepler Gemini API ile otomatik aciliyet skoru alır, yardımcılar bölgesel öncelik önerisi görür. Güvenlik odaklı tasarımı sayesinde tam konum yalnızca karşılıklı onaydan sonra paylaşılır, eşleşme sonrası gerçek zamanlı mesajlaşma açılır, şikayet sistemi kötüye kullanımı sınırlar.

ASP.NET Core Web API Blazor Server PostgreSQL Entity Framework Core SignalR JWT Authentication Leaflet.js Gemini API Prompt Engineering

Fino: Finansal Ajandam

Kişisel bütçe yönetimini otomatikleştiren, gizlilik odaklı (offline-first) bir mobil finansal ajanda. Fiş ve faturalardan veri girişini Google ML Kit tabanlı on-device OCR ile saniyelere indirir; harcama alışkanlıklarını cihaz içi SQLite (Drift) üzerinde yerel olarak saklar. Entegre Google Gemini AI finans koçu sayesinde harcama dağılımlarını analiz ederek kişiselleştirilmiş tasarruf içgörüleri üretir ve aylık görsel PDF raporları sunar.

Flutter Dart Riverpod Drift (SQLite) Clean Architecture Google Gemini API Google ML Kit (OCR) Offline-First

Taşınabilir Üretim ve Stok Takip Sistemi

Bir imalathanenin üretim ve stok süreçlerini dijitalleştirmek amacıyla geliştirilmiş, hiçbir kuruluma ihtiyaç duymadan (Portable/Self-Contained) doğrudan tek bir .exe üzerinden çalışan, SQLite tabanlı masaüstü ERP yazılımı.

.Net 8 Windows Forms C# SQLite Entity Framework Core ERP Stok Takip Yönetimi

Anlatmaca: Kelime Oyunu

Flutter ve MVVM mimarisiyle geliştirilmiş; Provider durum yönetimi, asenkron yerel veri işleme, ses efektleri ve dinamik skor takip mekanizması barındıran modern bir mobil kelime oyunu.

Flutter Dart JSON Parsing Provider (State Management) MVVM Architecture

ASP.NET Core MVC Entity Framework Core MS SQL Server Groq Cloud API REST API

Secure Exit IoT

Secure Exit, alev ve titreşim sensörleri aracılığıyla yangın veya deprem riskini otonom olarak algılayan, tehlike anında acil çıkış kapılarını ve yönlendirme aydınlatmalarını otomatik devreye sokan bir IoT projesidir. Veriler NodeMCU üzerinde işlenerek Firebase ile senkronize edilir; kullanıcılar mobil uygulama üzerinden canlı verileri izleyebilir ve sisteme manuel müdahalede bulunabilir.

Internet of Things (IoT) NodeMCU (ESP8266) Embedded C++ / Arduino Firebase Realtime Database Mobile App Development Sensors (Flame & Vibration) Emergency Systems
